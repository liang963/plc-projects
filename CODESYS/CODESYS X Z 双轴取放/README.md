# X–Z 双轴取放（CODESYS SoftMotion，CODESYS 3.5）

两轴取放程序：X 横移 + Z 升降，机械臂末端配真空吸盘。包含模式管理（初始化 / 手动 / 自动 / 急停）、单轴运动封装（使能、回零、点动、绝对定位、停止、复位）、取放步序与循环计数。

## 工程信息

| 项 | 内容 |
| --- | --- |
| 平台 | CODESYS 3.5（SoftMotion，`SM3_Basic`） |
| 编程 | 结构化文本（ST） |
| 轴数 | 2（X、Z），`AXIS_REF_SM3` 轴引用 |
| 最近修改 | 2026-10-21 |

## 程序结构

| 对象 | 类型 | 作用 |
| --- | --- | --- |
| `PRG_main` | 程序 | 主循环：模式机、使能请求汇总、点动放行、状态输出 |
| `PRG_Pick` | 程序 | 取放步序：定位、升降、真空、循环计数 |
| `FB_AxisCtrl` / `FB_AxisCtrlTk` | 功能块 | 单轴封装，每轴一套实例（轻量分层） |
| `FB_Homing` | 功能块 | 回零流程 |
| `FB_Jog` | 功能块 | 点动（手动模式） |
| `FB_Reinit` | 功能块 | 标准复位块 |
| `Axis_Type` | DUT | 轴参数与状态结构 |
| `GVL` | 全局变量 | 模式 `eMode`、HMI 位、轴状态汇总 |
| `E_Mode` | 枚举 | `INIT` / `MANUAL` / `AUTO` / `ESTOP` |

## 模式机

`GVL.eMode` 维护当前模式，`E_Mode` 四个值分别为初始化、手动、自动、急停：

| 行为 | 处理 |
| --- | --- |
| 切手动 / 切自动 | HMI 位 `bModeManual` / `bModeAuto` 触发 |
| 急停 | `ESTOP` 态下**所有轴使能请求恒为 FALSE**，输出全部断开 |
| 急停解除 | 落回 `MANUAL`，必须重新选自动才恢复生产 |
| 复位报警 | 清故障、重新上使能 |

## 单轴运动封装

每轴一个 `FB_AxisCtrl` 实例（`fbAxisX`、`fbAxisZ`），对外只暴露业务语义的接口，内部调 SoftMotion 标准块：

| 内部块 | 用途 |
| --- | --- |
| `MC_Power` | 使能 |
| `MC_Home` | 回零 |
| `MC_Jog` | 手动点动（正/反向） |
| `MC_MoveAbsolute` | 绝对定位（取料位、放料位、高/低位） |
| `MC_Halt` | 停止 / 暂停挂起 |
| `MC_Reset` | 清轴故障 |

封装对外给出 `bEnabled`（已使能）、`bHomed`（已回零）、`bReady` 等状态，`PRG_main` 把两轴的 `bReady` 组合成 `bAxesReady`（两轴均就绪），作为自动启动的前置条件。

## 取放流程

| 要素 | 说明 |
| --- | --- |
| 位置 | 取料位、放料位（水平）；高位（抬起）、低位（下降到位） |
| 末端 | 真空吸盘开 / 关 |
| 启动 | 启动一次取放（自动模式下有效） |
| 连续循环 | 使能后按「取料 → 抬起 → 移到放料位 → 下降 → 放件 → 抬起」重复 |
| 暂停 | 仅自动运行中有效：`MC_Halt` 原地停住两轴，**步序与真空状态保持不变**，恢复后从断点重新发定位指令续跑 |
| 停止 | 平稳取消连续循环：当前动作收尾后停在空闲，不硬切 |
| 计数 | `iCycleCount` 累计完成循环次数 |

## 运动参数

参数集中在 `Axis_Type` 里，分轴配置，HMI 可改：

| 参数 | 说明 |
| --- | --- |
| 自动速度 | 自动流程中的定位速度 |
| 加速度 / 减速度 | 定位与停止的加减速 |
| 加加速度 | jerk，限制柔性冲击，Z 轴下降段尤其明显 |
| 点动速度 | 手动模式点动速度 |
| 免回零 | `bSimNoHome`：仿真时使能即视为已回零；真机置 FALSE 走真实 `MC_Home` |

## 关键点

- **暂停不破坏步序**：挂起时只发 `MC_Halt`，步序变量与真空输出全部保持，恢复时重发当前步的定位指令——不需要从头再跑一遍。
- **急停切断使能请求**：不是在每个运动块里散着判断急停，而是在汇总层把两轴的使能请求统一压成 FALSE，避免漏改。
- **急停后必须重选自动**：解除急停回手动，按下启动不会自己进自动，防止误启动。
- **仿真/真机一套程序**：靠 `bSimNoHome` 切换免回零，不必为仿真单独维护一份工程。
- **回零状态锁存**：`FB_Homing` 的完成标志锁存，只有重新启动回零才清除，中途掉使能不会丢掉「已回零」这个事实。
