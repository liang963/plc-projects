# 模拟量的分段线性标定（折线插值）（CODESYS 3.5 库）

用折线点表把非线性模拟量换算成工程量：逐段求斜率，区间内线性插值，超出两端用首末段斜率延长；块内同时保留了「输入突变时按规划缓变输出」的第二个功能思路。

## 工程信息

| 项 | 内容 |
| --- | --- |
| 平台 | CODESYS 3.5，库工程（`.library`） |
| 编程 | 结构化文本（ST），按 PLCopen 风格封装状态机 |

| 最近修改 | 2026-10-15 |

## 数据结构

| 变量 | 说明 |
| --- | --- |
| `real_D[]` | 工程量点表（实际值） |
| `test_D[]` | 采样值点表（码值） |
| `point_1` | 点数，默认 10 |
| `ratio[]` | 每段折线斜率，预计算 |
| `real_D_now` | 当前采样值 |
| `out_D` | 换算后的工程量输出 |

## 算法

**1. 预计算斜率**

```
FOR n := 1 TO point_1 - 1 DO
    ratio[n] := (real_D[n+1] - real_D[n]) / (test_D[n+1] - test_D[n]);
END_FOR
```

一次算好 9 段斜率，之后每次换算只做一次除法。

**2. 按输入落在哪一段分别处理**

| 情况 | 处理 |
| --- | --- |
| 在第 `n` 段之间 | 以第 `n` 段起点为基准，按该段斜率线性插值 |
| 小于首点 | 用第 1 段斜率向下延长 |
| 大于末点 | 用最后一段斜率向上延长 |

**3. 端点保护**

用 `point_1` 判断下标范围，防止点数改小后数组越界（代码注释：`point判断，防止计算错误`）。

## 第二个功能：突变后的输出规划

代码里留了思路（尚未并入主流程）：输入值突变时，不把阶跃直接送到输出，而是先检测突变、生成一段从当前值到目标值的规划曲线，再按规划逐步输出。适合压力、流量这类不允许阶跃的回路。

## 状态机封装

和同类标定块一致，采用 PLCopen 风格封装：

| 状态 | 含义 |
| --- | --- |
| `DORMANT` | 等待 `xExecute` 上升沿 |
| `EXECUTING` | 换算进行中，`xBusy` 为 TRUE |
| `DONE` | 完成，`xDone` 置位 |
| `ERROR` | 出错，`eErrorID` 给出 `NO_ERROR` 之外的错误码 |
| `RESETTING` | `xExecute` 撤销后复位输出、释放资源 |

`ERROR` 枚举当前定义了两个值：`NO_ERROR` 和 `TIME_OUT`。

## 适用场景

温度、液位、流量、称重这类传感器，标称线性但实际曲线有弯折；用折线表比两点线性更接近真实曲线，比多项式拟合少算力——10 段查表加一次除法，扫描周期压力很小。
