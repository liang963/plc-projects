# 堆垛机：随机库位存取（S7-1200，TIA Portal V16）

仓储堆垛机仿真工程。`FB_WarreHouse` 用「空库位池 + 洗牌」选库位，同一轮内不重复；入库、出库各走独立流程块，叉车完成上/下/左/右动作。

## 随机库位算法

从变量命名可以看出是**洗牌（Fisher–Yates）式的随机取位**，避免「随机到已占用库位再重试」：

| 变量 | 作用 |
| --- | --- |
| `pool` | 空库位编号池 |
| `AvailableCount` | 当前可用库位数量 |
| `i`、`j`、`SwapTemp` | 洗牌下标与交换临时值 |
| `RandomNo` | 随机算法选出的库位号 |
| `RandomError`、`RdWord` | 随机数取值的错误码与中间字 |
| `个库位的占用状态`、`空库位数量` | 库位表与统计 |
| `一个扫描周期的启动请求` | 单周期触发 |
| `存货完成脉冲` | 任务完成脉冲 |
| `叉车上计时` | 叉车上升沿用的计时 |
| `正在执行任务，包括返回过程` | 任务状态说明 |

取位过程：按占用表重建 `pool` → 用 `LGF_RandomRange_Dint` 取一个下标 → 与该下标和末位交换 → 取走一个，`AvailableCount` 减一。复杂度 O(1)，且一轮之内不会重复。

## 实现要点

- **随机取位不重试**：空库位池 + 洗牌，取代「随机生成库位号，撞到占用就重抽」的做法，扫描周期稳定。
- **随机数来源**：库函数 `LGF_RandomRange_Dint` 内部读系统时间（`RD_SYS_T`）做种子，并用 `RandomError`、`RdWord` 检查取值是否有效。
- **分层**：`FB_AutoCtrl` 管自动起停，`FB_Inbound` / `Fb_Outbound` 管单一方向流程，`FB_WarreHouse` 管库位与叉车动作，互不越界。
- **完成信号**：任务用 `存货完成脉冲` 通知上层，`正在执行任务，包括返回过程` 区分「取货」和「返回」两个阶段。
