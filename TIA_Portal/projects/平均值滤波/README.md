# 平均值滤波（S7-1200，TIA Portal V16）

模拟量平均值滤波功能块。`FB_AvgFilter` 把采样值压进队列求算术平均，支持「去掉极值」模式和队列满/越界判断，`DB_FilterData` 存队列与统计量。

## 接口

| 类别 | 变量 | 说明 |
| --- | --- | --- |
| 输入 | `start` | 启动滤波 |
| 输入 | `reset` | 重置 |
| 输入 | `sample` | 采样请求，上升沿入队一个新数据 |
| 输入 | `newValue` | 新采集的原始数据 |
| 输出 | `average` | 平均滤波值 |
| 输出 | `count` | 有效样本数 |
| 输出 | `minValue` / `maxValue` | 队列最小值 / 最大值 |
| 输出 | `full` | 队列是否已满 |
| 输出 | `error` | 队列数组是否越界 |
| 静态 | `statTrig` | 采样上升沿检测（`R_TRIG`） |
| 静态 | `removeExtremum` | 是否去掉极值 |
| 静态 | `statCount` | 有效样本计数 |
| 临时 | `len`、`lower`、`upper`、`i`、`sumTmp`、`maxTmp`、`minTmp` | 求和与去极值的中间量 |

## 实现要点

1. **入队**：`sample` 上升沿（`statTrig`）把 `newValue` 写入队列，`count` 递增，写满后 `full` 置位。
2. **求平均**：遍历有效样本累加到 `sumTmp`，除以 `count` 得到 `average`。
3. **去极值**：`removeExtremum` 为真时先找 `maxTmp` / `minTmp`，用 `lower` / `upper` 界定参与平均的数据区间，即掐头去尾后再平均。
4. **保护**：数组下标越界时置 `error`；`reset` 清空队列与统计量。

界面说明与变量一一对应：`使能滤波`、`采样请求，上升沿入队一个新数据`、`新采集的原始数据`、`重置数组`、`有效样本数`、`平均滤波值`、`队列最小值`、`队列最大值`、`队列是否已满`、`队列数组是否越界`、`是否去掉极值`、`直接返回`。

## 地址

只使用 M 区（`%M0.0`、`%M0.1`、`%M10.0`、`%M100.0`–`%M100.7`），不占用过程 IO，可直接在仿真里监控变量。

## 适用场景

适用于把跳变的模拟量采样（如称重、位移、压力）做平滑处理：窗口长度与是否去极值都是块参数，同一块可复用于多路通道，每路一个背景 DB 即可。
