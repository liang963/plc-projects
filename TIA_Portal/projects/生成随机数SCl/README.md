# SCL 随机数生成（S7-1200，TIA Portal V16）

单独的 SCL 随机数练习工程。`随机数` 功能块用线性同余算式 `X(n+1) = (A × X(n) + C) mod M` 生成随机数，初值取自系统时间，输出按 `minValue` / `maxValue` 归一化。工程只有一个功能块和一个背景块，用于单独查看算法。

## 接口与参数

| 类别 | 变量 | 说明 |
| --- | --- | --- |
| 输入 | `minValue` / `maxValue` | 输出范围下限 / 上限 |
| 输出 | `random` | 生成的随机数（归一化后） |
| 参数 | `statSpeed` | 生成节奏 |
| 静态 | `A`、`C`、`M` | 线性同余的三个参数：乘数、增量、模数 |
| 静态 | `currentTime` | 读系统时间（`RD_SYS_T`）得到的种子源 |
| 静态 | `tmp_REAL` | 归一化中间值 |
| 静态 | `RET_VAL` | `RD_SYS_T` 的返回码 |

## 实现要点

1. **取种子**：用 `RD_SYS_T` 读 PLC 系统时间（`DTL`），取低位作为初始值，保证每次上电的序列不同。
2. **递推**：`X(n+1) = (A × X(n) + C) mod M`，用 `DWORD`/`UDINT` 的自然溢出实现取模，省掉除法。
3. **归一化**：把 `X` 折算成 0–1 的实数，再映射到 `minValue`–`maxValue`，得到可直接使用的 `random`。
4. **可控节奏**：`statSpeed` 控制生成间隔，便于观察输出序列。

## 说明

线性同余是最轻量的伪随机方案：只用一个乘法和一个加法，适合 PLC 这种没有浮点随机库的场合。代价是低位随机性偏弱，需要高质量随机时改用库函数或外部随机源；这里的用途是练习算法与 SCL 语法，随机序列的可重复性反而便于检查结果。
